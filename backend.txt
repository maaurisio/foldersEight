# 🚀 Node + Prisma + Docker Template

# ⚡ Cheat Sheet - Node + Prisma + MySQL + Docker (Docker-first)

## 🚀 Setup rápido

git clone <repo>           # Clonar proyecto
cd <proyecto>


crear archivo backend\.env
## ⚙️ Variables de entorno

NODE_ENV=development
PORT=3000
DB_HOST=mysql
DB_USER=root
DB_PASSWORD=root
DB_NAME=mydb
JWT_SECRET=ultresecretkeyforproduction
DATABASE_URL=mysql://root:root@mysql:3306/mydb
CORS_ORIGIN=http://localhost:3000


npm install


## definir modelo (usuario)

model Usuario {
  id       Int     @id @default(autoincrement())
  email    String  @unique
  password String
}

model TokenRevocado {
  id          Int      @id @default(autoincrement())
  token       String
  createAt    DateTime @default(now())
}

docker-compose down -v # borrar volumen
docker compose up -d --build      # Levantar servicios (mysql + backend)

## 🧱 Prisma (desde Docker)

👉 Modelos → `prisma/schema.prisma`

docker exec -it backend-backend-1 npx prisma migrate dev --name init   # Crear BD + tablas
docker exec -it backend-backend-1 npx prisma generate                  # Generar cliente
docker exec -it backend-backend-1 npx prisma studio    ## visualizar

(apagar y prender los servicios*)
probar nodemon


CODIGO---------
mkdir src\repositories src\controllers src\routes src\services src\middleware src\config 

repository -> services -> controller -> routes -> index.js


## SCALAR
docker exec -it backend-backend-1 npm install @scalar/express-api-reference

## ▶️ Run
docker compose up -d --build   # Reconstruir y levantar todo


## 🧪 Test
GET http://localhost:3000
GET http://localhost:3000/test-db


## ⚠️ Fix rápidos

* ❌ No hay tablas → `migrate dev`
* ❌ No conecta BD → `docker compose up -d`
* ❌ Error URL → revisar `.env`
* ❌ Usar localhost → usar `mysql` (nombre del servicio)

## 💡 Tips

* Todo comando Prisma → con `docker exec`
* Usa el nombre real del contenedor (`docker ps`)
* `prisma init` solo una vez


//insomnia (variables de entorno)
1. Configurar el Entorno (Una sola vez)
{
  "mi_token": ""
}

2. Configurar el LOGIN (Capturar el Token)
Ve a tu petición de Login.
Entra en la pestaña Scripts -> After-response.
Pega este código:

const body = JSON.parse(insomnia.response.body);
if (body.token) {
    insomnia.environment.set("mi_token", body.token);
}


3. Usar el Token en las rutas protegidas
Ve a registrar Tarea (o cualquier ruta que pida token).
En la pestaña Auth, selecciona Bearer Token.
En el campo "Token", escribe literalmente: {{ mi_token }}.
Tip: Si se pone azul, está bien vinculada.

4. Configurar el LOGOUT (Limpiar el acceso)
Ve a tu petición de Logout.
Entra en la pestaña Scripts -> After-response.
Pega este código:

insomnia.environment.set("mi_token", "");
